# Sales Dashboard 2026 — Mini Project

## Project Overview
This mini project presents a sales dashboard designed to analyze sales performance and communicate key business insights through visualizations.

## Objectives
- Monitor sales performance.
- Identify sales trends and patterns.
- Present important sales metrics in an interactive dashboard.

## Tools & Technologies
- Power BI
- Power Query
- DAX

## Project Files
- Power BI report (`.pbix`), if included
- Dashboard screenshots

## How to View
View the screenshots in this repository to preview the dashboard. If the Power BI report is included, download the `.pbix` file and open it using Power BI Desktop.
